## Terminology

:::slide{src="../../slides/lecture-03/slide-010.webp" n="10"} Terminology

- LLM = Large Language Model
- "A language model is a statistical or machine
- learning model that assigns probabilities to
- sequences of tokens."
:::

:::slide{src="../../slides/lecture-03/slide-012.webp" n="12"} Terminology

- LLM = Large Language Model
- Model size: billions of parameters or more
- Training data: 100s of billions of tokens or more
- Compute: a lot of GPUs
:::
